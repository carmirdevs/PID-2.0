# Plataforma de validación — PID 2.0

Módulo de cuestionarios académicos del proyecto doctoral PID 2.0. Se mantiene separado de la prueba de concepto (PoC) del modelo MTPD-ID.

## Seguridad

**Nunca publicar `app/config.local.php`**, contraseñas, secretos, tokens de invitación, bases de datos ni respuestas identificables. Usar una plantilla de configuración con valores ficticios.

## Estado

La incorporación del código fuente de la plataforma está pendiente de completar. No utilizar esta carpeta como despliegue funcional hasta verificar la publicación de todos los archivos y sus dependencias.
